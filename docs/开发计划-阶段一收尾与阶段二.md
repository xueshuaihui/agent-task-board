## 风险与注意

1. **Windows 打包无法交叉编译**：需要 Windows 机器/CI runner；sidecar node.exe 分发方案先在 macOS 上把路径解析逻辑写成平台无关。
2. **HTML 沙箱预览**是安全敏感项，实现前先定方案（独立源 WebView vs iframe sandbox），避免 XSS 进主窗口上下文。
3. **pdf.js worker** 在 Tauri 打包产物（tauri:// 协议）下的路径加载需要实测。
4. **签名**依赖 Apple Developer 账号与 Windows 代码签名证书，若没有则按降级方案文档化，不影响功能验收。
5. 自动备份定时器参照 `lease.service.ts` 的可注入定时器模式，保证可测试性。
