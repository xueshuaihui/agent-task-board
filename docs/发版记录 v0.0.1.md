## 4. 已知限制

1. **未签名**：首次打开需右键打开或 `xattr -cr`（手册 2.4）。
2. **DMG 生成走 hdiutil 兜底**：无头会话下 `bundle_dmg.sh`（osascript）必失败，属环境限制而非产物问题。
3. **x86_64 单架构**：arm64 原生/通用包未随本版发布，构建路径已文档化。
4. **sidecar node 不入库**：换机器打包前需按 README 重新拷入对应架构 node。
5. **HTML 预览沙箱、pdf.js worker** 等阶段二安全/兼容项未纳入本版。
