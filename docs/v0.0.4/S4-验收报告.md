## C) 人审与 none 直通行为回归 ✅

### 人审链路验证

**步骤记录**:

1. **创建任务** (review_mode=human)
   ```bash
   POST /api/v1/tasks
   {"title":"人审链路测试任务","review_mode":"human"}
   → {id: "T-1001", status: "BACKLOG", review_mode: "human"}
   ```

2. **移至待执行**
   ```bash
   POST /api/v1/tasks/T-1001/transition
   {"to":"READY"}
   → {status: "READY"}
   ```

3. **Agent 认领**
   ```bash
   MCP tools/call: claim_next_task
   → {task.status: "RUNNING", lease.run_id: "R-2001", lease.lease_id: "01a122ea-..."}
   ```

4. **完成任务**
   ```bash
   MCP tools/call: complete_task
   → {task_status: "REVIEW"}
   ```
   ✅ 任务状态变为 **REVIEW**（等待人工审核）

5. **提交审核**
   ```bash
   POST /api/v1/tasks/T-1001/review
   {"conclusion":"APPROVE","comment":"审核通过"}
   → {status: "DONE"}
   ```
   ✅ 任务状态变为 **DONE**

**完整链路**: BACKLOG → READY → RUNNING → **REVIEW** → DONE ✅

### none 直通链路验证


**完整链路**: BACKLOG → READY → RUNNING → **DONE** ✅
