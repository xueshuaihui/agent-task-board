### 1.3 四个一级暂不设二级的显式理由

教育学习/内容创作/方案写作/投资理财维持扁平。硬约束在迁移经济学上：**给有一级挂任何子级，该一级自身即失去叶子资格，全行必须改判**（0019 回填 + seed 重制 + 分布快照重写）。本批拍板范围是「编码下二级」，非编码三类没有第二个像阶段词这样的天然数据源（千问旧 catalog 实测只有一层分组词，抠不出可信二级），先立两级骨架、后续逐类单独立项细分（细分时只动一类，映射表加行即可）。

### 1.4 双角色词（阶段词）口径

- 阶段词**同时**是「编码开发」下的二级叶子（category 值）和 tags 里的产研阶段标签——拍板已接受卡片「分类徽标 + 同名标签」两行呈现的特例。
- 因此 `freeTagsOf` 需要特例：剔除集合从「全部叶子词」改为「叶子词 − 六个阶段词」（=「阶段词不再被洗、其余不变」）。若不加特例，生成器与写入侧会把 31 条内置的阶段标签重新洗光，直接违反拍板②。
- 千问 93 条不受影响（其 tags 已洗为空、永不含阶段词）；用户 custom 行的阶段词标签**不升格**为分类（分类只在 category 列，tags 仍是自由标签）。
