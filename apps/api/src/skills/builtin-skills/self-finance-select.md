# 智能选股

专业的 A 股选股工具，根据明确的条件筛选，综合结构化条件筛选结果（财务/行情/技术指标）、公开资讯与研报观点，产出候选股票清单与选股研究报告，支持对比选股、行情条件筛选、技术指标筛选与新闻驱动选股。

## 适用场景

| 类型 | 示例 |
| ------------ | ---------------------------------------------------------------------- |
| 多维条件筛选 | "筛选净利润增速超过30%且ROE大于15%的消费股"、"筛选市盈率低于20且ROE大于15%的股票" |
| 行情指标筛选 | "今日涨幅2-6%、量比>2、换手率8-20%、总市值<200亿的沪深A股"、"查找AI算力概念近一周涨幅前20的股票" |
| 技术指标筛选 | "MACD金叉的半导体股"、"突破20日均线、成交量放大的消费股" |
| 对比选股 | "从半导体板块里挑几只值得关注的"、"新能源方向推荐3-5只成长性较好的标的" |
| 新闻驱动选股 | "高端PCB订单排产到Q4，哪些相关公司值得关注"、"围绕AI眼镜产业链选股" |
| 题材/行业选股 | "机器人概念里有哪些核心标的"、"围绕低空经济主线筛选候选股" |

## 工作流程

1. **构造查询** - 按下方规则将选股需求整理为清晰、完整的 query 字符串
3. **输出结果** - 完整返回选股报告内容

## 查询构造规则

1. query 须清晰描述选股范围与筛选条件/策略，体现明确的选股意图,不能漏条件，多个条件要构造成“并且”逻辑，即同时满足用户提的所有条件；
2. 对于一些存在负向效果的指标需要增加下界兜底，避免选出不利于投资的结果，比如盈利且市盈率低于15倍的低估值股票，需要增加市盈率大于0的条件；
3. 用户指定的所有量化条件（财务指标/行情指标/技术指标的阈值、区间、排序、数量上限等）与重点方向必须完整保留，不得丢失；
4. 若限定行业/概念/题材范围，须在 query 中明确写出；
5. 如果是定时任务一定要增加"定时任务"前缀标识;
6. 对于有歧义的需求要先理解清楚，构造出清晰可查又能满足需求的query，比如，‘帮我选主力资金净流入最高的10只股票’，需要构造成‘筛选主力资金净流入top10的股票’，让query有清晰不矛盾的条件。

**条件筛选：**

```
筛选净利润增速超过30%且ROE大于15%的消费股
筛选沪深A股：今日涨幅2-6%、量比>2、换手率8-20%、总市值<200亿、市净率≤4
查找AI算力概念板块近一周涨幅前20的股票
均线多头排列且MACD金叉的半导体概念股
```

**对比/范围选股：**

```
从半导体板块里挑选3-5只成长性较好的标的
围绕机器人概念，推荐若干核心受益标的并说明逻辑
```

**新闻驱动选股：**

```
高端PCB订单排产到Q4，筛选相关受益公司
围绕AI眼镜产业链主线选股，重点关注上游光学与整机环节
```

## 脚本返回格式

脚本默认返回JSON。
result.result.result.final_deliverable_md: 最终交付的 MD 文件
result.result.result.final_deliverable_html: 最终交付的 HTML 文件
result.result.result.is_empty_result: 最终交付物是否为空结果

## 结果处理

1.交付物检查：读取result.result.result.is_empty_result的值是否为True/true,如果为True/true，直接向用户发起选股条件澄清（比如条件放宽、条件改写等）后重新调用本skill，【后面步骤的不执行】。
2.通过交付物检查没问题后，处理步骤如下：
- a.取 final_deliverable_md 的值，注意，接口返回的是文件路径，**不是直接的文字内容**
- b.读取 final_deliverable_md 文件中的 Markdown 文本内容
- c.**如果内容包含“当前条件筛选结果为空"**,向用户发起选股条件澄清（比如条件放宽、条件改写等）后重新调用本skill，【后面步骤的不执行】
- d.**将 Markdown 内容完整输出给用户**，仅移除所有 emoji，其余内容不得修改、截断或省略
- f.提示用户报告已生成，将文件路径输出给用户，格式如下：

```
选股报告已完成。⚠️ 报告仅供参考，不构成实际投资建议。
MEDIA:<final_deliverable_md>
```

> ⚠️ 只交付文本内容，禁止交付任何文件，必须把 md 内容取回来完整展示。

## 限制与注意

| 项目 | 说明 |
| ------------ | -------------------------------------------------- |
| **标的范围** | 仅支持 A 股股票，最多30只，超过数量建议分批次调用，不支持基金、期货、指数、ETF、非上市公司 |
| **候选数量** | 结果清单最多包含 30 只个股，默认候选上限 30 只 |
| **数据真实性** | 候选股票、代码与数值均来自筛选/行情/资讯/研报材料，禁止编造 |
| **响应时间** | 选股需等待几分钟，最大可能20分钟，设置足够超时 |
