# 学生评语生成器（生成即用·期末评语）

> 定位：通过简短交互确认必要参数，产出可直接使用的期末评语（成品/半填充/模板三模式）；用户明确要求文件时再执行落盘流程。

## ★ 核心：输出模式选择器（主动弹窗确认）
Skill 被触发后先识别用户是否已经明确模式；未明确时再通过当前环境可用的交互方式一次性提供选项：
- 🅰 **成品**：用户提供真实数据 → 直接产出可使用的完整评语；需要文件时按落盘门禁和当前环境能力生成。
- 🅱 **半填充**：用户提供部分数据 → 填入已知、空缺标 `【待补：xxx】`。
- 🅲 **模板**：只给骨架 + 占位符 + 选型说明，供反复套用。

选完主模式后，只确认仍缺失的文件格式、风格和关键参数；当前环境没有交互控件时使用清晰的文字选项。不要重复询问用户已经给出的信息。

## 🔒 隐私与数据保护（强制前置，处理未成年人个人信息）

**触发本 skill 后、采集学生数据前，必须先加载 `references/privacy.md` 并整体遵循。** 学生评语涉及未成年人个人信息，落盘文件极易被转发/留存/泄露，以下为不可绕过的强制约束：

1. **最小化采集**：只需"生成评语所必需"的字段（学生标识=姓名或学号二选一 + 行为事实）。**不主动索要**身份证号、家庭住址、家长联系方式、精确排名、医疗/心理诊断、家庭情况；用户若夹带，须提示"此字段并不需要，可不提供"，并在落盘时默认剔除或脱敏。
2. **默认脱敏档位**：落盘前须确认档位——①【实名档】仅限教师本人本地留存、文件顶部强制加隐私声明水印；②【匿名/化名档】（默认推荐）用于任何分享/上传/流转场景，姓名换学号或化名、排名区间化（"班级前10%"而非"第3名"）。
3. **敏感表述红线**：评语正文与落盘文件禁止写入心理诊断词（焦虑症/抑郁/多动）、家庭隐私定性（离异/贫困/留守）、贬损标签（差生/问题学生）；一律改为可观察行为描述。涉及学生情绪/心理/家庭的情况，提示"建议仅口头或面谈沟通，不写入可流转的评语文件"，默认不落盘。
4. **隐私声明**：落盘文件顶部逐字放置 privacy.md 第五节的隐私声明（依据《个人信息保护法》《未成年人保护法》）。

## 落盘前强制确认（Hard Gate）

无论当前环境是否支持弹窗（AskUserQuestion 类能力），**落盘前必须先回显、经用户确认后方可写文件**。此为强制流程，弹窗路径与文字兜底路径一律适用，不得跳过。

### 强制回显清单（落盘前逐项展示）
1. **将产出的文件清单**：如 `评语表.md`、`评语表.csv`、`评语表.xlsx`（openpyxl 不可用时降级为 md+csv 并说明）。
2. **关键参数**：模式（成品/半填充/模板）、语气、长度约束、是否含改进建议、涉及学生数量。
3. **脱敏档位**：当前为【实名档】还是【匿名/化名档】；默认推荐匿名/化名档；若为实名档，明确提示"仅限本地留存、不得外传，文件将加隐私声明水印"。
4. **敏感字段处置**：若输入含高敏信息（精确排名、心理/家庭情况等），回显"以下字段不会写入落盘文件"。

### 确认与纠正
- 展示后须等待用户明确回复"确认落盘 / 修改档位 / 调整参数 / 取消"。
- 文字兜底路径同样在此暂停，**不得确认前直接落盘**；用户可在此纠正模式、档位、字段与措辞。
- 仅在收到明确确认后调用 `scripts/export_comments.py` 落盘（分享/流转场景默认加 `--anonymize`）。

> 变更说明：旧版文字兜底路径会绕过确认直接落盘，导致 FAQ 承诺的"落盘前可纠正"失效。本段将确认闸门提升为**弹窗与文字路径共用的强制前置步骤**。

## 触发与示例问法
- 「帮我做个期末评语」
- 「生成一份[具体场景]的期末评语」
- 「我要期末评语的模板」
- 关键词：期末评语、学生评语

## 第一支柱：参数确认
激活后只确认尚未明确的参数；可使用当前环境支持的交互控件，也可使用文字一次性确认：
- ① 学生数据（姓名/成绩/特长/表现 csv）；② 语气（鼓励/中肯/正式）；③ 长度与重点；④ 是否含改进建议。

## 决策 / 选型指引
先扬具体优点再给可改建议；用行为描述替代标签；差异化避免模板感。对临界生给信心与路径，对优生给挑战。

## 固定输出结构（5 段）
1. **模式确认回显**：复述所选模式与关键参数，避免跑偏。
2. **选型 / 参数摘要**：用表格列出本次交付的范围与口径。
3. **主体交付物**：默认给出可复制的评语；用户明确要求文件并通过落盘确认后，再生成「期末评语」文件。
4. **使用说明 / 精修提示**：告诉用户下一步怎么填、怎么改、注意什么。
5. **反模式提醒 + 下一步**：附常见坑与可继续的动作（如「生成配套习题」「出PPT」）。

## 异常处理（三级响应）
- **模糊需求**（如只说「做个期末评语」）：一次性反问核心参数（对象/目标/约束），不硬编。
- **超边界**（如要法律背书/实时数据）：明确说明能力边界并建议转诊（律师/数据源），提供结构草案。
- **数据缺失**：切「半填充」模式，空缺标 `【待补：xxx】`，不编造关键数字。

## 反模式（8条）
1. 不看需求直接套模板：先确认目标与约束，再选模板，避免产出「正确但无用」。
2. 模板硬塞不相关数据：用户只给部分数据时用「半填充」模式，空缺处标 `【待补：xxx】`，不编造数字。
3. 一次给太多文件：先预览将产出的文件清单，用户确认后再落盘，避免无关交付物。
4. 风格不统一：成品模式套统一的样式规范（字体、配色、编号、术语），保证多次输出一致。
5. 跳过异常处理：模糊需求必须先反问，超边界明确说明并转诊，不强行硬答。
6. 把建议当交付：用户要正文时给可直接使用的评语；用户要文件时，确认后实际生成并回显路径，不把“可以生成”当成已交付。
7. 忽视合规边界：科研伦理/数据/涉法内容标注「建议复核/咨询专业人士」，不替代责任。
8. 不说明如何使用：每个交付物附使用说明与精修提示，告诉用户下一步怎么改、往哪填。

## FAQ（10条）
Q1：我想要的是思路不是文件，能只给模板吗？
A：可以。选择「模板」模式即可，只给骨架、占位符和说明，不落盘成品。

Q2：我有真实数据，能直接帮我填好出图/出文档吗？
A：选「成品」模式，把数据贴给本 skill（CSV/表格/直接描述），它会按出版级样式直接产出可运行文件。

Q3：我只有一部分数据怎么办？
A：选「半填充」模式，已给数据填入、空缺处标 `【待补：xxx】`，你补完即可用。

Q4：生成的文件放在哪？
A：只有你明确要求文件并确认落盘后，才写入当前任务允许的输出目录，并回显完整路径；环境不支持写文件时会直接返回可复制内容。

Q5：输出格式能选吗？
A：自带脚本支持 md/csv，并在 openpyxl 可用时支持 xlsx；其他格式只有当前环境具备相应能力时才提供。

Q6：风格/配色/口径能自定义吗？
A：可以。在参数确认时选择风格预设或提供自定义要求，成品模式会套用所选规范。

Q7：内容不准确或有误怎么办？
A：先给模式确认回显与参数摘要，你可在落盘前纠正；落盘后也可让我局部修改。

Q8：涉及科研伦理/法律的内容可靠吗？
A：伦理/数据/涉法内容仅提供结构草案与风险提示，关键项请由专业人士复核，本 skill 不替代责任。

Q9：能一次产出多个关联文件吗？
A：可以。落盘前会列出本次必要的文件清单，你确认后再一次性生成。

Q10：和同类已发 skill 什么区别？
A：本 Skill 主打参数引导和可直接使用的评语正文；用户明确要求文件时还能通过自带脚本批量导出。

## 落地文件清单（本 skill 直接产出）
① 评语表 md/csv/xlsx：姓名或学号/评语正文/改进建议（由 `scripts/export_comments.py` 落盘，csv 用 UTF-8-BOM 便于 Excel 打开，xlsx 需平台预置 openpyxl、缺失时自动降级为 md+csv 且不联网安装）；② 批量生成模板（CSV 入参骨架）；③ 家校沟通版精简评语。
> 落盘统一走 `scripts/export_comments.py`；分享/流转场景加 `--anonymize` 走匿名档。

## 质量与一致性约束
- **未成年人隐私保护（第一约束）**：遵循 `references/privacy.md`——最小化采集、默认脱敏、敏感表述红线、落盘文件加隐私声明；情绪/心理/家庭信息默认不写入可流转文件。
- **诚实交付**：成品模式套用统一样式规范（字体、配色、编号、术语）保证一致性，但评语仍需教师**逐条人工把关**（如纪律/迟到等表述是否适合写入），本 skill 不宣称"跑完即得、无需复核"。
- 涉科研伦理/数据/法律内容标注「建议由专业人士复核」，不替代责任。
- 所有交付物落盘后回显完整路径，并附一句使用提示。
