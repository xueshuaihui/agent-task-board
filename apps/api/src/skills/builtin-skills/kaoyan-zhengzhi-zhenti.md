
# 考研政治真题拆解

把 2010-2026 年考研政治真题读穿后，反推出的命题底层逻辑与可迁移做题方法论。核心理念：**不背题，算题**。

## 能力清单

1. **逐题六维拆解**：原题还原 → 命题方式分析 → 考点定位 → 陷阱识别 → 做题思路 → 延伸价值
2. **10 类陷阱识别**：每类含识别信号、心理机制、破解动作、典型真题
3. **13 种审题方法**：可复用的三步操作流程
4. **考点密度导航**：150 题按考点归类的密度分布，指导复习优先级

## 核心工作流

### 工作流 A：拆解一道真题（旗舰场景）

用户贴出一道题时，按六维输出：

1. **考点定位与答案**：判断科目、章节、考点，给出答案
2. **命题方式分析**：材料来源（时政/名言/科技/寓言）、设问指向、题型结构
3. **逐项判断**：每个选项/题肢对应的原理与对错判断（表格呈现）
4. **命题陷阱**：指出本题使用的陷阱类型，引用 `07-陷阱库/` 对应卡片
5. **做题思路**：3-4 步的实战操作路径，标注"几秒出答案"级别的效率点
6. **延伸价值**：可迁移方法、相关"错误观点对子"、给下一年考生的提示

格式参照 `references/samples/2026-Q1-Q4-breakdown.md`。

### 工作流 B：解释某选项为什么错

1. 读出该选项的陷阱类型（对照下方速查表）
2. 读取 `07-陷阱库/` 对应卡片，输出：为什么错（心理机制）+ 识别信号 + 破解动作
3. 补充 2-3 道同陷阱的历年真题作为印证

### 工作流 C：查询命题规律

- 马原 → 读 `01-马原/马原-命题总规律.md`（核心：情境→原理映射）
- 其他科目 → 读对应科目的 `命题总规律.md`
- 输出时保留"材料来源表 + 设问指向 + 错误选项制造手法"的完整框架

### 工作流 D：复习优先级建议

读 `01-马原/马原-考点地图.md`，按密度排序输出优先级表，并结合用户的时间约束给取舍建议。

### 工作流 E：做题方法咨询

根据用户描述的题型/困难，从 `08-审题方法/` 调用对应方法卡，输出：适用场景 + 操作步骤 + 实战演示。

## 十大陷阱速查表（内嵌，无需读文件）

| 陷阱 | 识别信号 | 高发科目 |
|---|---|---|
| 绝对化限定词 | 只有/唯一/完全/彻底/根本取决于 | 全部 |
| 偷换哲学立场 | 直观/机械/物自体/唯意志/感知即存在 | 马原 |
| 夸大主观能动性 | 意识+决定/创造/取代/摆脱 | 马原 |
| 关系错位 | 经典概念对（实践/认识等）+方向反了 | 马原 |
| 张冠李戴 | 眼熟内容+犹豫主体 | 史纲 |
| 偷换限定词 | 灵魂/精髓/核心/首要/根本 | 毛中特/习概 |
| 无中生有 | 首次/最/已经等强断言 | 习概/时政 |
| 拔高评价 | 已经/彻底/覆灭/实现 | 史纲 |
| 时间线错位 | 题干有"X大之前/X时期"等时间边界 | 史纲 |
| 概念越界 | 设问"X属于什么/X包括什么" | 思修法基 |

**重要提醒**：高危词是概率武器不是铁律——用关键词初筛，用题干依据终裁。

## 铁律

1. 所有答案和考点判断必须基于知识库内容或可验证的真题事实，不编造
2. 拆解时明确标注"设问落点"，区分"本身正确"与"符合题意"
3. 计算题（剩余价值率等）必须展示公式和分母陷阱提醒
4. 遇到知识库未覆盖的题目，用速查表和方法卡推理，并注明"基于方法论推断"
