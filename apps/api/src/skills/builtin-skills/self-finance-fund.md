
# 公募基金查询与分析

面向公募基金的数据查询与分析工具：输入一句自然语言的基金问题，自动识别基金、调用数据接口，返回带关键数据和风险提示的中文结论。

## 适用场景

| 类型 | 示例 |
| --- | --- |
| 净值与行情 | 最新净值/累计净值、日涨跌幅、历史净值走势；场内ETF最新价、成交量、涨跌幅等 |
| 业绩与规则 | 阶段收益、同类排名、申购赎回费率、限购状态、交易规则 |
| 诊断与风险 | 基金综合诊断、风险指标、业绩比较基准 |
| 持仓与配置 | 重仓股、行业偏好、行业集中度、债券配置、债券评级 |
| 对比与组合 | 多基金业绩对比、相关性分析、组合诊断、组合回测 |
| 推荐与主题选基 | 基金推荐（如“年收益10%左右的稳健基金”）、板块/主题基金筛选（如“医药基金”“AI半导体代表性基金”）、某主题/板块基金的投资价值分析 |
| 策略与资讯 | 投资策略、市场热点、基金相关财经新闻 |

## 工作流程

1. **构造查询** - 按下方规则组装 query 字符串（自然语言，一句话即可）
2. **调用脚本** - 执行脚本，调用时 **必须设置 timeout ≥ 900 秒**
3. **获取文件** - 从返回 JSON 中取 `final_deliverable_md` 路径，读取该 MD 文件，取回 Markdown 全文
4. **输出结果** - 将 MD 全文完整展示给用户，末尾附文件路径

## 查询构造规则

**基本格式：**

```
<基金名称或代码> + <想问的问题>
```

**核心原则：保证「基金名/代码完整 + 意图完整」即可，无需拆得碎。**

- 本 skill 内部是一个多轮 mini-agent，会自己完成实体识别、维度拆解与多接口并发查询，**不需要上层把一个问题拆成多个子 query**
- **多维度问题直接一句话传入**：如“帮我分析 002170，它的持股、主要方向和成长空间”直接原句传，不要拆成“持股”“方向”“成长空间”三次调用
- **多只基金对比也写在同一条里**：如“对比中欧医疗健康混合A和工银前沿医疗股票A”一条即可，skill 会批量查询并对比
- **必须保留的两类信息**：① 基金的完整名称或 6 位代码（不要只传“这只基金”“上面那只”等指代词；基金全名不要省略 A/C 类别后缀）；② 用户的原始意图（包括“推荐”“对比”“是否有投资价值”这类分析型诉求，不要改写成单纯的数据查询）
- 不要自行给 query 加用户没提的限定条件，以免缩小或偏离原始需求

**示例：**

```
# 基金识别（只给简称或模糊名称）
易方达蓝筹的代码是多少？
005827是什么基金？

# 净值与行情查询
东方人工智能主题混合A最新净值和涨跌幅
518880黄金ETF今日涨跌幅、收盘价、成交量
证券ETF512880近5个交易日股价和成交量
黄金ETF 2026年6月每日价格

# 基金情况/简况（多维度一句话传入，不拆）
查001076简况
帮我分析一下 002170，它的持股、主要方向和成长空间
分析一下民生加银精选混合这支基金

# 业绩与交易规则
005827近一年收益怎么样？在同类里排第几？
这个基金现在还能买吗？限购吗？

# 诊断与风险分析
帮我诊断一下005827
这只基金风险高吗？最大回撤多少？

# 持仓与配置
易方达蓝筹重仓了哪些股票？
这只债基的信用评级分布怎么样？

# 多基金对比与组合（多只写在同一条里，不拆）
005827和110011哪个更值得定投？
对比中欧医疗健康混合A和工银前沿医疗股票A
对比一下易方达创新驱动混合和广发创新升级混合近1年收益率和同类排名
我持有这几只基金，帮我分析下组合风险

# 推荐与主题选基
哪几款基金年收益10%左右比较稳健？推荐一下
医药有哪些推荐的基金？
储能板块的基金有投资价值吗？

# 策略与资讯
最近有什么值得关注的基金市场热点？
帮我搜下医药基金最近的新闻
```

## 脚本调用

```bash
python3 {baseDir}/scripts/script.py "<按上方规则构造的查询字符串>"
```

> ⚠️ **超时设置**：复杂分析（多基金、多维度）需多轮数据查询，调用时 **必须设置 timeout ≥ 300 秒**。

## 脚本返回格式

脚本默认返回 JSON：

```
result.result.final_deliverable_md: 最终交付的 MD 文件路径
```

## 结果处理（重要）

脚本返回的是文件路径，**不是直接的文字内容**，必须按以下步骤处理：

1. 只取 `final_deliverable_md` 的值
2. 读取 `final_deliverable_md` 文件中的 Markdown 文本内容
3. **将 Markdown 内容完整输出给用户**，仅移除所有 emoji，其余内容不得修改、截断或省略
4. 若内容中出现"需要补充信息：XX"，直接向用户反问该项信息；基金名称/代码识别失败时按原文转达未找到原因及建议
5. **透出规则（来源声明）**：当回复中使用了本 skill 返回的具体内容（净值、行情、诊断、持仓等实际数据或分析结论），见最后的数据来源章节，需严格诚实透出对应的数据来源，不得省略数据来源。

```
⚠️ 内容仅供参考，不构成实际投资建议。
MEDIA:<final_deliverable_md>
```

> ⚠️ 只交付文本内容，禁止交付任何文件，必须把 md 内容取回来完整展示。

## 限制与注意

| 项目 | 说明 |
| --- | --- |
| **覆盖范围** | 仅覆盖公募基金（含场内ETF、联接、LOF、QDII、FOF、REITs），不含私募、银行理财、信托 |
| **不支持个股** | 个股行情、个股财报、选股筛选等请使用股票类工具，本 skill 无法承接 |
| **不支持期货/外汇** | 期货、外汇、债券现券、加密货币等非基金标的均不支持 |
| **不做交易** | 仅查询与分析，无法执行申购、赎回、定投等任何交易操作 |
| **不做预测** | 不提供未来收益预测，不做收益承诺；但**可以**基于历史业绩、风险指标筛选和推荐候选基金、分析板块基金的配置价值——推荐类需求属于本 skill 能力范围，结论会附风险提示且不构成投资建议 |
| **基金识别** | 用户给出简称或模糊名称时 skill 会自动识别；识别失败会说明原因，必要时引导用户补充基金全称或 6 位代码 |
| **循环上限** | 内部最多进行 4 轮数据查询，达到上限自动汇总；复杂多基金问题可能触发上限，此时结论基于已查到的数据 |
| **响应时间** | 简单查询约 1-3 min，多基金/多维度分析可达 5-10 分钟，需设置足够超时；不要因耗时顾虑而改用自身知识直接回答基金数据问题，自行回答极易出现净值/收益数据错误 |
