# 股票板块深度分析报告

专业的股票板块（行业/概念/题材）研究分析工具，生成多维度股票板块分析研究报告，支持指定的具体的股票板块整体研究分析和多股票板块对比。

## 适用场景

| 类型         | 示例                                                                   |
| ------------ | ---------------------------------------------------------------------- |
| 股票板块深度研究 | "帮我分析一下半导体板块"、"生成新能源板块深度报告"、"帮我整理一份港股创新药板块近期走势与估值修复空间的深度研究报告"                     |
| 股票板块行情分析 | "芯片板块近期涨跌报告"、"军工板块近7日走势如何"                        |
| 股票板块异动追踪 | "帮我分析半导体板块今日行情和异动，包括板块涨跌幅、主力资金流向、领涨领跌个股"                       |
| 股票板块投资建议 | "光伏板块值得投资吗"、"消费板块现在可以布局吗"                         |
| 多股票板块对比   | "对比半导体和新能源板块"、"医药板块和消费板块哪个更值得关注"             |
| 个股板块归属/联动   | "宁德时代所属的板块怎么样"             |
| 股票板块资金面   | "银行板块资金流向分析"、"电子板块主力资金近期怎么样"、"分析股市资金流出的板块及个股"                   |

## 不适用场景

> ⚠️ 本 Skill 的核心定位是「**股票板块/行业/概念/题材 × 分析研究**」，缺少任意一个要素均不适用，请转用其他 Skill。以下为常见不支持情形：

| 不支持情形              | 示例                                                            | 说明                                          |
| ----------------------- | --------------------------------------------------------------- | --------------------------------------------- |
| **个股深度研究**        | "帮我研究贵州茅台"、"分析宁德时代的投资价值"、"请对物理AI板块的国内龙头标的进行深度分析，比如科大讯飞、虹软科技"                    | 个股研究请使用 self-finance-report skill      |
| **非板块/行业**         | "沪深300ETF值得买吗"、"美元指数怎么看"，"整理容百科技各个业务板块的深度研究报告"                          | 本工具仅支持股票板块/行业/概念，不支持指数、ETF、具体公司的业务板块分析等 |
| **事件资讯查询**        | "半导体板块有什么新闻"、"光伏行业最近有什么政策"                | 属于资讯查询，非板块整体深度研究，请用self-finance-news skill               |

## 查询构造规则

1. query 须清晰描述需要分析研究的具体的股票板块（行业/概念/题材）和需求，体现明确的股票板块分析/深度研究意图；
2. 用户指定的重点方向必须完整保留，不得丢失；
3. 如果是定时任务一定要增加“定时任务”前缀标识。

**股票板块研究：**

```
深度分析半导体板块
芯片板块近期涨跌报告
分析新能源板块的投资价值，重点关注资金面和政策面
光伏板块近7日行情走势分析
军工板块现在值得投资吗
```

**多股票板块对比：**

```
对比半导体和新能源板块的投资前景
医药板块和AI板块，哪个更值得关注
对比消费和电子板块，重点关注资金面和技术面
```

**带时间范围：**

```
芯片板块近7日涨跌报告
新能源板块近30日资金流向分析
```

> 时间范围说明：支持「今日」「近7日/一周」「近15日」「近30日/近一个月」，默认近7日。最大不超过31天。

## 结果处理

接口返回的是文件路径，**不是直接的文字内容**，处理步骤如下：

1. 取 final_deliverable_md 的值
2. 读取 final_deliverable_md 文件中的 Markdown 文本内容
3. **将 Markdown 内容输出给用户**，需做两处处理：① 移除所有 emoji；② 将正文中所有 `[文字](url)` 形式的引用链接连同方括号里的来源名一起整个删除、不保留任何文字与链接，删后适当整理多余空格与标点；其余内容不得修改、截断或省略
5. 正文展示完毕后，必须输出 `MEDIA:<final_deliverable_md>` 附上 MD 文件：

```
xxx报告已生成。
⚠️ 报告仅供参考，不构成实际投资建议。
MEDIA:<final_deliverable_md>
```

> ⚠️ 必须把 md 内容取回来完整展示（不可只给文件路径），内容展示完毕后再附上 md 文件。

## 限制与注意

| 项目         | 说明                                               |
| ------------ | -------------------------------------------------- |
| **研究范围** | 主要支持A股板块/行业/概念/题材                    |
| **多板块限制** | 单次调用多板块对比最多支持3个板块，如果超过3个建议分批调用                        |
| **时间范围** | 默认近7日，最大31天，如果超过31天建议向用户澄清需求                                |
| **响应时间** | 深度研究需等待几分钟，最大可能20分钟，设置足够超时 |
