
# 股票深度研究报告

专业的股票深度研究分析工具，生成多维度投资分析报告，支持单股研究和多股对比（最多三只）。

## 适用场景

| 类型         | 示例                                                             |
| ------------ | ---------------------------------------------------------------- |
| 单股深度研究 | "帮我研究一下贵州茅台"、"生成宁德时代深度报告"                   |
| 多股深度对比 | "比较比亚迪和宁德时代"、"对比茅台和五粮液的投资价值"（最多三只） |
| 获取投资建议 | "XXX值得买入吗"、"XXX的估值合理吗"、"XXX有什么投资风险"          |

## 不适用场景

> ⚠️ 本 Skill 的核心定位是「**上市股票 × 整体深度分析**」，缺少任意一个要素均不适用，请转用其他 Skill。以下为常见不支持情形：

| 不支持情形              | 示例                                                            | 说明                                          |
| ----------------------- | --------------------------------------------------------------- | --------------------------------------------- |
| **信息获取 / 事件影响** | "比亚迪的BC电池技术怎么样"、"先正达上市对恒力石化有什么影响"    | 属于信息查询或事件分析，非个股整体深度研究    |
| **非股票标的**          | "半导体行业前景如何"、"新能源板块怎么看"、"沪深300ETF值得买吗"  | 本工具仅支持上市股票，不支持行业、板块、ETF等 |
| **非上市公司**          | "分析字节跳动的投资价值"、"华为值得关注吗"                      | 非上市公司缺乏公开财务数据，无法进行深度研究  |
| **数据查询**            | "贵州茅台现在股价多少"、"比亚迪的ROE是多少"、"宁德时代的市盈率" | 属于具体数据点查询，非深度研究报告            |

## 工作流程

1. **代码转名称** - 若输入为股票代码，先通过**转换步骤**转换为股票名称
2. **构造查询** - 按下方规则用股票名称构建 query 字符串
3. **调用脚本** - 远程 API 默认超时 1200 秒（20 分钟）。调用时 **必须设置 timeout ≥ 1200 秒**。
4. **输出结果** - 完整返回报告文件路径

## 股票代码处理规则

> ⚠️ 本 Skill **只接受股票名称**作为研究标的，**不接受股票代码**。若用户输入的是股票代码，必须先通过搜索将其转换为股票名称，再进入后续流程。

**识别方式：** 用户输入中有股票代码（如 `600309`）或带交易所前缀/后缀的证券代码（如 `SH600309`、`00700.HK`、`TSLA`），均视为股票代码。

**转换步骤**

1. 识别用户输入中是否包含股票代码
2. 通过网络搜索工具调用查询该代码对应的股票全称（例如搜索 `"600309 股票名称"` 或 `"600309 是什么股票"`）
3. 确认名称后，用**名称**替换代码，继续后续流程
4. 若搜索结果存在歧义，先向用户确认再继续

**示例：**

| 用户输入                 | 转换结果                 | 说明                                   |
| ------------------------ | ------------------------ | -------------------------------------- |
| 600309可以投资吗         | 万华化学可以投资吗       | A 股代码要搜索得到股票名称             |
| 00700怎么样？            | 腾讯控股怎么样？         | 港股代码搜索得到对应的股票名称         |
| 我可以买300565吗         | 我可以买科信技术吗       | 将相对应的股票代码转化为对应的股票名字 |
| 贵州茅台是好的投资标的吗 | 贵州茅台是好的投资标的吗 | 已是名称，直接使用，无需转换           |

## 查询构造规则

query 须清晰描述研究标的和需求，体现明确的研究意图；用户指定的重点方向必须完整保留，不得丢失。如果是定时任务一定要增加“定时任务”前缀标识。

**单股研究：**

```
深度研究贵州茅台
投资东方财富是一个好的选择吗
分析宁德时代的投资价值，重点关注财务质量和估值水平
分析东方财富，重点关注行业地位、赛道景气度和近期股价走势，给出投资建议
```

**多股对比：**

```
对比分析茅台和五粮液，哪个更值得持有
对比比亚迪和宁德时代，重点关注各自的竞争护城河和成长性
对比隆基绿能、通威股份、晶澳科技，重点关注行业地位和财务质量
```

## 脚本调用

```bash
python3 {baseDir}/scripts/script.py "<按上方规则构造的查询字符串>"
```

> ⚠️ **超时设置**：远程 API 默认超时 1200 秒（20 分钟）。调用时 **必须设置 timeout ≥ 1200 秒**。

## 脚本返回格式

脚本默认返回JSON
result.result.result.final_deliverable_md: 最终交付的 MD文件
result.result.result.final_deliverable_html: 最终交付的 HTML文件

## 结果处理

接口返回的是文件路径，**不是直接的文字内容**，处理步骤如下：

1. 取 final_deliverable_md 的值
2. 读取 final_deliverable_md 文件中的 Markdown 文本内容
3. **将 Markdown 内容输出给用户**，需做两处处理：① 移除所有 emoji；② 将正文中所有 `[文字](url)` 形式的引用链接连同方括号里的来源名一起整个删除、不保留任何文字与链接，删后适当整理多余空格与标点；其余内容不得修改、截断或省略
4. 正文展示完毕后，必须输出 `MEDIA:<final_deliverable_md>` 附上 MD 文件：

```
xxx报告已生成。
⚠️ 报告仅供参考，不构成实际投资建议。
MEDIA:<final_deliverable_md>
```

> ⚠️ 必须把 md 内容取回来完整展示（不可只给文件路径），内容展示完毕后再附上 md 文件。

## 限制与注意

| 项目         | 说明                                               |
| ------------ | -------------------------------------------------- |
| **研究范围** | 主要支持A股、港股、美股主流上市公司                |
| **多股限制** | 多股对比最多支持3只                                |
| **响应时间** | 深度研究需等待几分钟，最大可能20分钟，设置足够超时 |
