
# 财经资讯简报生成

专业的财经资讯聚合工具，支持市场简报、个股/板块资讯、个性化标的资讯聚合。

## 适用场景

| 类型       | 示例                                   |
| ---------- | -------------------------------------- |
| 定时简报   | 开盘早报、收盘午报、收盘晚报、财经日报 |
| 个股资讯   | XXX个股资讯、XXX股票新闻               |
| 板块/行业  | XXX板块资讯、XXX行业新闻               |
| 个性化资讯 | 带持仓/关注列表的定制化资讯            |

## 工作流程

1. **构造查询** - 按下方规则组装 query 字符串
2. **调用脚本** - 远程 API 默认超时 1200 秒（20 分钟）。调用时 **必须设置 timeout ≥ 1200 秒**。
3. **获取内容** - 读取返回的 MD 文件，取回 Markdown 全文
4. **输出结果** - 完整展示内容，末尾附文件路径

## 查询构造规则

**基本格式：**

```
<需求描述>，我的财经画像是：<关注股票>，<关注行业>，<关注板块>；我的现有持仓列表为<持仓股票>。如果是定时任务一定要增加“定时任务”前缀。
```

**示例：**

```
# 简单查询（无画像）
帮我收集今日财经早报

# 个股/板块查询
帮我查询中国海油的最新市场资讯
查一下半导体板块最近新闻

# 个性化查询（带画像）
帮我收集今日收盘晚报，我的财经画像：我关注中国海油、海康威视股票，关注能源和半导体板块；我持仓个股：招商银行
```

## 脚本调用

```bash
python3 {baseDir}/scripts/script.py "<按上方规则构造的查询字符串>"
```

> ⚠️ **超时设置**：远程 API 默认超时 1200 秒（20 分钟）。调用时 **必须设置 timeout ≥ 1200 秒**。

## 脚本返回格式

脚本默认返回JSON
result.result.result.final_deliverable_md: 最终交付的 MD文件
result.result.result.final_deliverable_html: 最终交付的 HTML文件

## 结果处理（重要）

脚本返回的是文件路径，**不是直接的文字内容**，必须按以下步骤处理：

1. 只取 final_deliverable_md 的值
2. 读取 final_deliverable_md 文件中的 Markdown 文本内容
3. **将 Markdown 内容输出给用户**，需做两处处理：① 移除所有 emoji；② 将正文中所有 `[来源](url)` 形式的溯源链接连同方括号里的来源名一起整个删除、不保留任何文字与链接，删后适当整理多余空格与标点；其余内容不得修改、截断或省略
4. 正文展示完毕后，必须输出 `MEDIA:<final_deliverable_md>` 附上 MD 文件：

```
⚠️ 内容仅供参考，不构成实际投资建议。
MEDIA:<final_deliverable_md>
```

> ⚠️ 必须把 md 内容取回来完整展示（不可只给文件路径），内容展示完毕后再附上 md 文件。

## 限制与注意

| 项目               | 说明                                                                             |
| ------------------ | -------------------------------------------------------------------------------- |
| **简报定位**       | 本工具产出为资讯简报，适合快速了解市场资讯；如需深度分析，请使用其他专业分析工具 |
| **不支持实时股价** | 此工具用于资讯聚合，无法完成实时股价查询                                         |
| **响应时间**       | 处理复杂，需等待几分钟，最多可达20分钟，需要设置足够超时                         |
| **需求主体**       | query 必须包含明确的需求主体（如：财经早报、XXX个股资讯）                        |
| **股票代码转换** | 查询含股票代码时，**必须**先用搜索工具将代码转为股票名称（如600000→浦发银行），再用名称查询。禁止直接使用股票代码。 |
