
# 龙虎榜解读

专业的A股龙虎榜数据解读工具。支持解读最近一个已披露的交易日（T-1，每日收盘后约18:00更新），同时支持指定具体日期或最近N个交易日汇总解读（最多30个交易日）。

报告将围绕以下维度生成：
- **核心观点**：龙虎榜整体概况、资金主线判断、市场情绪与持续性
- **资金动向概览**：机构席位净买入/净卖出TOP5、北向资金动向、游资席位活跃度
- **题材主线**：资金抱团/分歧的热点题材、细分赛道逻辑、题材轮动
- **异动归因**：上榜个股或题材的催化事件、政策/消息驱动
- **机构资金动向**：机构席位、北向资金、游资席位的买卖方向与力度
- **代表个股**：重点上榜个股的行情、上榜原因、席位性质与量价配合
- **风险分析**：高位股风险、情绪退潮风险、追高风险、监管风险

## 适用场景

| 类型             | 示例                                                             | 说明                                          |
| ---------------- | ---------------------------------------------------------------- | --------------------------------------------- |
| 全市场龙虎榜解读 | "解读今日龙虎榜"、"今天龙虎榜有什么看点"                       | 默认取最近已披露交易日                        |
| 游资/席位跟踪    | "章盟主今日上榜了哪些股票"、"分析方新侠席位动向"               | 基于营业部↔游资映射，识别知名游资风格         |
| 机构/北向动向    | "今天机构大幅买入哪些股票"、"北向资金龙虎榜动向"               | 机构专用、沪股通/深股通席位统计               |
| 多日区间汇总     | "最近5天龙虎榜资金主线"、"近一周游资动向"                      | 最多支持最近30个交易日汇总                  |
| 连板/强势股分析  | "分析今日连板股的龙虎榜"、"高位股资金分歧怎么看"               | 结合龙虎榜资金博弈判断接力或分歧              |

## 不适用场景

> ⚠️ 本 Skill 的核心定位是「**龙虎榜 × 复盘/解读/分析/研究**」，缺少任意一个要素均不适用，请转用其他 Skill。以下为常见不支持情形：

| 不支持情形              | 示例                                                            | 说明                                          |
| ----------------------- | --------------------------------------------------------------- | --------------------------------------------- |
| **实时股价 / 行情数据** | "贵州茅台现在股价多少"、"比亚迪今天涨了多少"                  | 属于行情数据查询，请使用 finance_data         |
| **非龙虎榜类资讯**      | "今天半导体板块新闻"、"宁德时代最新公告"                      | 属于资讯查询，请使用 finance_news             |
| **个股深度研究**        | "分析贵州茅台投资价值"、"比亚迪估值合理吗"                    | 属于深度研究，请使用 finance_report           |
| **非A股标的**           | "港股腾讯控股龙虎榜"、"美股特斯拉资金动向"                    | 本工具仅支持A股龙虎榜数据                   |
| **超范围日期**          | "近半年龙虎榜汇总"、"2024年全年龙虎榜"                        | 当前最多支持最近30个交易日区间                |

## 工作流程

1. **代码转名称** - 若输入为股票代码，先转换为股票名称
2. **构造查询** - 按下方规则用股票名称、日期或日期范围构建 query 字符串
3. **调用脚本** - 远程 API 默认超时 1200 秒（20 分钟）。调用时 **必须设置 timeout ≥ 1200 秒**。
4. **输出结果** - 完整返回报告文件路径

## 查询构造规则

query 须清晰描述龙虎榜解读需求，体现明确的解读/分析/研究意图；用户指定的重点方向必须完整保留，不得丢失。如果是定时任务一定要增加“定时任务”前缀标识。

**全市场龙虎榜：**

```
解读今日龙虎榜
分析今天龙虎榜的资金动向和游资风格
看看今日龙虎榜有哪些亮点
```

**游资/席位跟踪：**

```
分析方新侠今日上榜的股票
查看今天知名游资参与了哪些股票
```

**机构/北向动向：**

```
今天机构席位大幅买入哪些股票
北向资金今日龙虎榜净买入个股
```

**指定日期或区间：**

```
解读2025年7月18日的龙虎榜
分析贵州茅台2025年7月18日的龙虎榜
最近5天龙虎榜资金主线
近5个交易日龙虎榜游资动向
2025-07-01到2025-07-20龙虎榜汇总
20250701-20250720龙虎榜汇总
2025-07-01~2025-07-20龙虎榜汇总
```

## 脚本调用

```bash
python3 {baseDir}/scripts/script.py "<按上方规则构造的查询字符串>"
```

> ⚠️ **超时设置**：远程 API 默认超时 1200 秒（20 分钟）。调用时 **必须设置 timeout ≥ 1200 秒**。

## 脚本返回格式

脚本默认返回 JSON。在 `result.result.result` 中：
- `final_deliverable_md`: 最终交付的 Markdown 文件
- `final_deliverable_pdf`: 最终交付的 PDF 文件
- `final_deliverable_html`: 最终交付的 HTML 文件

## 结果处理

接口返回的是文件路径，**不是直接的文字内容**，处理步骤如下：

1. 取 `final_deliverable_md` 的值
2. 读取 `final_deliverable_md` 文件中的 Markdown 文本内容
3. **将 Markdown 内容输出给用户**，需做两处处理：① 移除所有 emoji；② 将正文中所有 `[文字](url)` 形式的引用链接连同方括号里的来源名一起整个删除、不保留任何文字与链接，删后适当整理多余空格与标点；其余内容不得修改、截断或省略
4. 正文展示完毕后，必须输出 `MEDIA:<final_deliverable_md>` 附上 MD 文件：

```
龙虎榜解读报告已生成。
报告仅供参考，不构成实际投资建议。
MEDIA:<final_deliverable_md>
```

> ⚠️ 必须把 md 内容取回来完整展示（不可只给文件路径），内容展示完毕后再附上 md 文件。

## 限制与注意

| 项目         | 说明                                               |
| ------------ | -------------------------------------------------- |
| **数据范围** | 主要支持A股主板、科创板、创业板、北交所龙虎榜数据 |
| **数据时效** | 默认最近已披露交易日（T-1）；当日收盘后约18:00前尚未披露当日榜，会自然落到上一交易日 |
| **日期支持** | 支持单日（今日/YYYY-MM-DD/YYYYMMDD/YYYY年M月D日）、区间（YYYY-MM-DD到YYYY-MM-DD、YYYYMMDD-YYYYMMDD、YYYY-MM-DD~YYYY-MM-DD）及相对天数（最近N天/近N日/过去N个交易日，N支持阿拉伯数字与中文数字），最多30个交易日 |
| **响应时间** | 解读分析需等待几分钟，最大可能20分钟，设置足够超时 |
| **解读定位** | 本工具侧重资金博弈、题材逻辑和席位行为分析，不构成投资建议  |
